لوحة إدارة مزونة

الدخول يتم بـ GitHub Token — هو نفسه مفتاح الحماية الحقيقي. يُتحقق منه فورًا، ويُحفظ بهذا التبويب فقط ويُمسح عند إغلاقه.

إعدادات المستودع
  1. افتح github.com/settings/personal-access-tokens/new (Fine-grained token).
  2. Repository access ← Only select repositories ← مستودع الموقع فقط.
  3. Permissions ← Contents ← Read and write.
